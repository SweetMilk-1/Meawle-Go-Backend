## Бизнес-правила

1. **Емкость домика:** Домик имеет фиксированную вместимость (capacity)
2. **Текущая занятость:** Текущее количество котов в домике (current_occupancy)
3. **Свободные места:** available_spaces = capacity - current_occupancy
4. **Один кот - один домик:** Кот может находиться только в одном домике одновременно
5. **Проверка владельца:** Только владелец кота (или администратор) может помещать/удалять кота из домика
6. **Обновление вместимости:** Нельзя уменьшить вместимость домика ниже текущего количества котов
7. **Удаление домика:** При удалении домика все связи с котами удаляются автоматически

## API эндпоинты

### Публичные (доступны всем):
- `GET /api/v1/cat-houses` - список всех домиков
- `GET /api/v1/cat-houses/{id}` - информация о домике
- `GET /api/v1/cat-houses/{id}/cats` - коты в домике
- `GET /api/v1/cat-houses/{id}/with-cats` - домик с котами

### Защищенные (требуют аутентификации):
- `POST /api/v1/cat-houses` - создание домика
- `PUT /api/v1/cat-houses/{id}` - обновление домика
- `DELETE /api/v1/cat-houses/{id}` - удаление домика
- `GET /api/v1/cat-houses/cats/{catId}/occupancy` - информация о размещении кота
- `POST /api/v1/cat-houses/cats/{catId}/add` - поместить кота в домик
- `DELETE /api/v1/cat-houses/cats/{catId}/remove` - удалить кота из домика

## Тестирование

1. Скомпилировать приложение: `go build ./cmd/api/main.go`
2. Запустить тестовый скрипт: `./test_cat_houses.sh`
3. Для тестирования защищенных эндпоинтов:
   - Зарегистрировать пользователя: `POST /api/v1/auth/register`
   - Войти в систему: `POST /api/v1/auth/login`
   - Использовать JWT токен в заголовке `Authorization: Bearer <token>`
