# Meawle

**Meawle** - это REST API сервис для управления профилями кошек, построенный на Go с использованием чистой архитектуры.

## 🐱 О проекте

Meawle предоставляет API для управления пользователями и их питомцами (кошками). Сервис поддерживает регистрацию пользователей, аутентификацию через JWT, CRUD операции для кошек и управление породами кошек.

## 🏗️ Архитектура

Проект построен по принципам чистой архитектуры с четким разделением ответственности:

### Структура проекта

```
meawle/
├── cmd/api/                    # Точка входа приложения
│   ├── config/                # Загрузка конфигурации
│   ├── di/                    # Dependency Injection
│   ├── routes/                # Настройка маршрутов
│   ├── server/                # Управление сервером
│   └── main.go               # Главная функция
├── internal/                  # Бизнес-логика
│   ├── config/               # Конфигурация приложения
│   ├── database/             # Управление БД
│   ├── handlers/             # HTTP обработчики
│   ├── middleware/           # Промежуточное ПО
│   ├── models/               # Модели данных
│   ├── repositories/         # Слой доступа к данным
│   ├── services/             # Бизнес-логика
│   └── utils/                # Вспомогательные утилиты
├── migrations/               # Миграции базы данных
└── examples/                 # Примеры использования
```

## 🚀 Быстрый старт

### Предварительные требования

- Go 1.25.1 или выше
- SQLite3

### Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone <repository-url>
   cd meawle
   ```

2. **Установка зависимостей:**
   ```bash
   go mod download
   ```

3. **Настройка переменных окружения (опционально):**
   ```bash
   export PORT=:8080
   export DB_PATH=app.db
   export JWT_SECRET=your-secret-key
   export LOG_LEVEL=info
   ```

4. **Запуск приложения:**
   ```bash
   go run cmd/api/main.go
   ```

5. **Проверка работы:**
   ```bash
   curl http://localhost:8080/health
   ```

## 📋 API Endpoints

### Аутентификация

- `POST /api/auth/login` - Вход в систему
- `POST /api/auth/register` - Регистрация пользователя

### Пользователи

- `GET /api/users` - Получить список пользователей (только для администраторов)
- `GET /api/users/{id}` - Получить пользователя по ID
- `PUT /api/users/{id}` - Обновить пользователя
- `DELETE /api/users/{id}` - Удалить пользователя

### Кошки

- `GET /api/cats` - Получить список кошек
- `GET /api/cats/{id}` - Получить кошку по ID
- `POST /api/cats` - Создать новую кошку
- `PUT /api/cats/{id}` - Обновить кошку
- `DELETE /api/cats/{id}` - Удалить кошку

### Породы кошек

- `GET /api/cat-breeds` - Получить список пород
- `GET /api/cat-breeds/{id}` - Получить породу по ID
- `POST /api/cat-breeds` - Создать новую породу (только для администраторов)
- `PUT /api/cat-breeds/{id}` - Обновить породу (только для администраторов)
- `DELETE /api/cat-breeds/{id}` - Удалить породу (только для администраторов)

Более подробно можно посмотреть [здесь](API.md)

## 🗄️ База данных

Проект использует SQLite3 с миграциями. Структура базы данных:

### Таблицы

- `users` - Пользователи системы
- `cats` - Профили кошек
- `cat_breeds` - Справочник пород кошек

### Миграции

Миграции находятся в папке `migrations/` и выполняются автоматически при запуске приложения.

## 🔐 Аутентификация

Аутентификация реализована с использованием JWT (JSON Web Tokens). Для доступа к защищенным эндпоинтам необходимо:

1. Получить токен через `/api/auth/login`
2. Добавить заголовок `Authorization: Bearer <token>` к запросам

## 🔧 Разработка

### Структура кода

Проект следует принципам чистой архитектуры:

- **Handlers** - обработка HTTP запросов
- **Services** - бизнес-логика
- **Repositories** - доступ к данным
- **Models** - структуры данных

### Добавление нового функционала

1. Создать модель в `internal/models/`
2. Добавить репозиторий в `internal/repositories/`
3. Реализовать сервис в `internal/services/`
4. Создать обработчик в `internal/handlers/`
5. Добавить маршруты в `cmd/api/routes/`
6. Создать миграции в `migrations/`
